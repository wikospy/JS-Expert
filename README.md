# Level 7 - Frontend Ecosystem

## Topics

- TypeScript concepts, while keeping project examples JavaScript-first
- npm and `package.json`
- Git and GitHub workflows
- Modern frontend tooling and build systems
- Environment variables and safe configuration
- Production builds and deployment
- Frontend performance budgets
- Accessibility and auditing
- Unit, integration, and end-to-end testing

## Level project

Design, build, test, optimize, and deploy a **production-quality frontend
application** from an idea. Include an architecture decision record, Git
history, environment configuration, automated checks, accessibility evidence,
performance measurements, and a deployment checklist.

Lessons: [npm, tooling, and types](./01-npm-tooling-and-types.js) and
[Git, production, and quality](./02-git-production-and-quality.js).
